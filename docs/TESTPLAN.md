# Test Plan for Account Management System

This test plan covers the business logic of the current COBOL-based Account Management System. The system allows users to view account balance, credit funds, debit funds (with insufficient funds validation), and exit the application. The initial balance is set to 1000.00 and is maintained in memory during the session.
